# 모찌 공장 MVP 작업 목록

## 1. 기반 구성

- [x] `index.html`에 Phaser 3 CDN과 게임 진입점을 연결한다.
  - Live Server 확인: 브라우저에서 페이지를 열었을 때 가로형 게임 영역이 표시되고, 콘솔 오류가 없다.

- [x] 시작, 플레이, 결과 화면을 별도 장면 파일로 만들고 시작 → 플레이 → 결과 전환과 다시 하기를 연결한다.
  - Live Server 확인: 시작하기를 누르면 플레이 화면으로, 결과 화면 보기를 누르면 결과 화면으로 이동하며, 다시 하기를 누르면 초기 플레이 화면으로 돌아간다.

- [x] 게임 파일을 화면, 주문, 모찌 제작, 진행 상태 역할로 나눈 모듈 구조를 만든다.
  - Live Server 확인: 게임 화면이 이전과 같이 표시되고, 콘솔 오류가 없다.

## 2. MVP 규칙 확정

- [x] MVP에서 사용할 모찌 종류, 주문 표현 방식, 제작 조작 방식, 제한 시간, 판매 금액, 확장 비용과 완료 조건을 정해 상수로 기록한다.
  - Live Server 확인: 게임을 열었을 때 정한 초기 시간과 주문 정보가 화면에 표시된다.

## 3. 기본 플레이 화면

- [x] 가로형 게임 화면에 주문 영역, 제작 영역, 남은 시간, 보유 금액 영역을 배치한다.
  - Live Server 확인: 각 영역이 겹치지 않고 한 화면에서 읽을 수 있다.

- [x] 게임 시작 시 손님의 모찌 주문 한 건을 생성해 화면에 표시한다.
  - Live Server 확인: 새로고침하면 주문 영역에 제작해야 할 모찌가 표시된다.

## 4. 모찌 제작과 판매

- [x] 플레이어가 제작 조작으로 모찌 한 개를 선택하거나 만들 수 있게 한다.
  - Live Server 확인: 제작 조작 후 현재 만든 모찌가 제작 영역에 표시된다.

- [x] 만든 모찌가 현재 주문과 일치할 때 판매하고 보유 금액을 올린다.
  - Live Server 확인: 주문과 같은 모찌를 만들면 금액이 정해진 만큼 증가한다.

- [x] 판매가 끝나면 다음 주문을 생성해 표시한다.
  - Live Server 확인: 올바른 모찌를 판매한 직후 주문 내용이 새 주문으로 바뀐다.

- [x] 주문과 다른 모찌를 만든 경우에는 판매와 금액 증가가 일어나지 않게 한다.
  - Live Server 확인: 다른 모찌를 만들어도 보유 금액과 주문이 바뀌지 않는다.

## 5. 제한 시간과 결과

- [x] 게임 시작과 동시에 제한 시간을 줄이고 남은 시간을 화면에 갱신한다.
  - Live Server 확인: 남은 시간이 1초마다 감소한다.

- [x] 제한 시간이 끝나면 제작과 판매를 멈추고 실패 결과를 표시한다.
  - Live Server 확인: 시간이 0이 되면 더 이상 금액이 오르지 않고 실패 메시지가 보인다.

- [x] 정한 MVP 완료 조건을 달성하면 성공 결과를 표시하고 플레이를 멈춘다.
  - Live Server 확인: 완료 조건을 달성하면 성공 메시지가 보이고, 주문 처리와 시간 진행이 멈춘다.

## 6. 가게 확장

- [x] 보유 금액이 확장 비용에 도달하면 가게 확장을 실행할 수 있게 한다.
  - Live Server 확인: 필요한 금액을 모은 뒤 확장 조작을 할 수 있다.

- [x] 확장 시 비용을 차감하고 가게의 확장 상태를 화면에 반영한다.
  - Live Server 확인: 확장 후 보유 금액이 줄고, 가게 화면이 확장된 상태로 바뀐다.

## 7. 재시작과 최종 점검

- [ ] 성공 또는 실패 결과에서 게임을 처음 상태로 다시 시작할 수 있게 한다.
  - Live Server 확인: 재시작하면 시간, 금액, 주문, 가게 상태가 초기값으로 돌아간다.

- [ ] Live Server에서 시작부터 성공·실패·재시작까지 전체 흐름을 점검한다.
  - Live Server 확인: 콘솔 오류 없이 주문 제작, 판매, 확장, 성공 또는 실패, 재시작이 모두 동작한다.

## 8. 연습 모드

- [x] 시작 화면에 연습하기 버튼을 두고, 시간 제한 없이 단계별 안내를 따라 모찌 한 개를 만드는 튜토리얼을 만든다.
  - Live Server 확인: 연습하기를 누르면 안내 창과 화살표가 순서대로 주문, 반죽, 밀기, 과일, 감싸기, 판매를 안내하고, 안내가 끝나면 자유 연습과 실전 시작이 동작한다.

## 9. 1단계 과일 손질 → 2단계 영업

- [x] 1단계 손질: 60초 동안 손님 없이 과일 그림을 눌러 씻기 2번 → 자르기 2번으로 손질하고, 손질된 과일 2개를 재고로 쌓는다.
  - Live Server 확인: 시작하면 남은 시간이 01 : 00부터 줄고, 과일 칸의 분홍 숫자와 목표 손질 개수가 손질할 때마다 2씩 는다.

- [x] 12개 이상 손질하면 영업 시작 버튼으로 2단계로 넘어가고, 60초가 끝나면 12개 이상일 때 자동으로 넘어가며 모자라면 실패한다.
  - Live Server 확인: 12개 전에 영업 시작을 누르면 안내가 나오고, 시간이 끝났을 때 12개 미만이면 실패 결과가 나온다.

- [x] 2단계 영업: 90초 동안 손님이 계속 오고, 판매하면 곧바로 다음 손님이 온다. 영업 중에는 손질할 수 없다.
  - Live Server 확인: 영업을 시작하면 남은 시간이 01 : 30으로 바뀌고, 판매 직후 손님 받기 없이 새 손님이 온다.

- [x] 주문한 과일의 재고가 0개일 때만 다음 손님 버튼으로 손님을 넘긴다.
  - Live Server 확인: 재고 없는 과일이 주문되면 다음 손님 버튼이 나오고, 누르면 판매 수는 그대로인 채 새 손님이 온다.

- [x] 연습 모드 안내를 손질 → 영업 시작 → 모찌 만들기 → 판매 → 단계 규칙 설명 순서로 바꾼다.
  - Live Server 확인: 연습하기를 누르면 안내가 영업 시작 버튼과 1·2단계 규칙, 다음 손님 버튼을 차례로 설명한다.

- [x] 안내가 끝나면 자유 연습을 실전과 같은 1단계 손질부터 시간 제한 없이 시작하고, 손질한 과일을 모두 쓰면 연습을 끝낸다.
  - Live Server 확인: 안내 마지막 [다음]을 누르면 재고·금액이 0인 손질 단계로 바뀌고, 재고를 다 쓰면 연습 완료 문구가 나온다.

## 10. 라운드 진행과 여러 개 주문

- [x] 판매 목표를 채우면 다음 라운드의 손질 단계로 넘어가고, 라운드마다 판매 목표·손질 목표·주문 개수·줄 선 손님 수가 늘어난다.
  - Live Server 확인: 1라운드에서 10개를 팔면 2라운드 손질 단계(01 : 00, 손질 재고 18개 목표)로 바뀌고, 재고·금액·가게 확장이 이어진다.

- [x] 한 손님이 여러 종류의 모찌를 여러 개 주문하고, 만든 모찌가 하나씩 체크되며 모두 만들면 한꺼번에 판매한다.
  - Live Server 확인: 2라운드부터 주문 카드에 모찌가 2~3개 보이고, 하나 만들 때마다 체크가 붙으며, 마지막을 만들면 합계 금액이 오른다.

- [x] 손님이 줄을 서고, 맨 앞 손님의 참을성 게이지가 다 줄면 판매 없이 떠난다.
  - Live Server 확인: 2라운드에는 뒤에 작은 손님 1명, 3라운드에는 2명이 보이고, 기다리면 왼쪽 게이지가 줄어 손님이 떠난다.

- [x] 결과 화면에 통과한 라운드 수와 총 판매 개수를 표시하고, 연습 안내에 라운드·줄·참을성 설명을 추가한다.
  - Live Server 확인: 실패하면 결과 화면에 통과 라운드와 총 판매가 보이고, 연습 안내에 새 설명 단계가 나온다.

## 11. 소리

- [x] 직접 작곡한 밝은 배경 음악을 첫 화면부터 반복 재생하고, 모든 화면 오른쪽 아래에 음악 끄기/켜기 버튼을 둔다.
  - Live Server 확인: 첫 화면을 한 번 클릭하면 음악이 시작되고, 음악 끄기를 누르면 멈추며 게임 화면으로 가도 꺼진 상태가 유지된다.

- [x] 씻기·자르기·반죽·모찌 완성·손님 도착 효과음을 또렷하게 다시 만들고, 도착 순간에 소리를 낸다.
  - Live Server 확인: 각 동작마다 서로 다른 소리가 들리고, 모찌가 주문 칸에 닿을 때 "뽀롱" 소리가 난다.
