# 모찌 공장 디자인 가이드

## 방향

- 가로형 화면에서 주문 확인, 제작, 판매와 확장을 빠르게 읽는 밝고 다정한 카페형 공장 분위기.
- 그래픽 스타일은 둥근 도형의 밝은 카툰 스타일이며, 모찌와 과일은 단순한 표정·하이라이트로 그리고 짙은 보라색의 굵고 둥근 외곽선으로 통일한다.

## 색상

- 배경은 아주 연한 크림 `#FFF9EE`, 넓은 면은 연한 초록 `#DDF3DD`와 연한 파랑 `#DDEEFF`를 사용한다.
- 주문·강조는 연한 노랑 `#FFF1B8`, 보조 카드는 연한 분홍 `#FFDDE7`, 확장·특별 상태는 연한 보라 `#E8DFFF`를 사용한다.
- 본문과 외곽선은 짙은 보라 `#5A466B`, 기본 버튼 글자는 흰색으로 하며 상태 구분에만 색을 사용한다.

## 글꼴과 타이포그래피

- 둥근 느낌의 고딕 계열 시스템 글꼴을 쓰고, 가늘거나 장식적인 글꼴은 사용하지 않는다.
- 1단계 제목은 48~64px 굵게(게임·결과 제목), 2단계 영역 제목은 26~32px 굵게(주문·제작·보유 금액)로 한다.
- 3단계 본문·버튼은 20~26px로 하며, 핵심 숫자와 주문 이름은 2단계 이상으로 표시한다.

## 화면 배치

- 상단에는 게임 제목 또는 진행 상태를 두고, 남은 시간과 보유 금액을 떨어뜨려 배치한다.
- 중앙 왼쪽은 손님 주문 카드, 중앙은 제작 조작과 현재 만든 모찌, 중앙 오른쪽은 가게 확장 상태로 둔다.
- 하단에는 충분한 간격의 주요 조작 버튼을 한 줄로 두고, 시작·결과 화면은 중앙 정렬과 가장 큰 핵심 버튼 하나를 유지한다.

## 버튼과 그래픽 요소

- 버튼은 큰 둥근 사각형에 12px 안팎의 짙은 보라 외곽선과 아래쪽 진한 색 입체 그림자를 두며, 누를 때 그림자를 줄인다.
- 기본 버튼은 분홍, 긍정·판매 버튼은 초록, 확장 버튼은 보라를 사용한다.
- 카드와 패널은 둥근 모서리와 얇은 외곽선, 아주 약한 단색 그림자를 사용하고, 아이콘은 원·타원과 작은 잎·볼터치·표정으로 구분한다.

## 하지 않을 것

- 어두운 배경, 사실적 사진, 금속·유리 재질, 날카로운 모서리와 강한 네온 색을 사용하지 않는다.
- 화면을 작은 텍스트나 장식으로 과밀하게 만들지 않고, 색만으로 상태를 구분하지 않는다.
