# 모찌 공장 MVP 작업 목록

## 1. 기반 구성

- [x] `index.html`에 Phaser 3 CDN과 게임 진입점을 연결한다.
  - Live Server 확인: 브라우저에서 페이지를 열었을 때 가로형 게임 영역이 표시되고, 콘솔 오류가 없다.

- [x] 시작, 플레이, 결과 화면을 별도 장면 파일로 만들고 시작 → 플레이 → 결과 전환과 다시 하기를 연결한다.
  - Live Server 확인: 시작하기를 누르면 플레이 화면으로, 결과 화면 보기를 누르면 결과 화면으로 이동하며, 다시 하기를 누르면 초기 플레이 화면으로 돌아간다.

- [ ] 게임 파일을 화면, 주문, 모찌 제작, 진행 상태 역할로 나눈 모듈 구조를 만든다.
  - Live Server 확인: 게임 화면이 이전과 같이 표시되고, 콘솔 오류가 없다.

## 2. MVP 규칙 확정

- [ ] MVP에서 사용할 모찌 종류, 주문 표현 방식, 제작 조작 방식, 제한 시간, 판매 금액, 확장 비용과 완료 조건을 정해 상수로 기록한다.
  - Live Server 확인: 게임을 열었을 때 정한 초기 시간과 주문 정보가 화면에 표시된다.

## 3. 기본 플레이 화면

- [ ] 가로형 게임 화면에 주문 영역, 제작 영역, 남은 시간, 보유 금액 영역을 배치한다.
  - Live Server 확인: 각 영역이 겹치지 않고 한 화면에서 읽을 수 있다.

- [x] 게임 시작 시 손님의 모찌 주문 한 건을 생성해 화면에 표시한다.
  - Live Server 확인: 새로고침하면 주문 영역에 제작해야 할 모찌가 표시된다.

## 4. 모찌 제작과 판매

- [ ] 플레이어가 제작 조작으로 모찌 한 개를 선택하거나 만들 수 있게 한다.
  - Live Server 확인: 제작 조작 후 현재 만든 모찌가 제작 영역에 표시된다.

- [ ] 만든 모찌가 현재 주문과 일치할 때 판매하고 보유 금액을 올린다.
  - Live Server 확인: 주문과 같은 모찌를 만들면 금액이 정해진 만큼 증가한다.

- [ ] 판매가 끝나면 다음 주문을 생성해 표시한다.
  - Live Server 확인: 올바른 모찌를 판매한 직후 주문 내용이 새 주문으로 바뀐다.

- [ ] 주문과 다른 모찌를 만든 경우에는 판매와 금액 증가가 일어나지 않게 한다.
  - Live Server 확인: 다른 모찌를 만들어도 보유 금액과 주문이 바뀌지 않는다.

## 5. 제한 시간과 결과

- [ ] 게임 시작과 동시에 제한 시간을 줄이고 남은 시간을 화면에 갱신한다.
  - Live Server 확인: 남은 시간이 1초마다 감소한다.

- [ ] 제한 시간이 끝나면 제작과 판매를 멈추고 실패 결과를 표시한다.
  - Live Server 확인: 시간이 0이 되면 더 이상 금액이 오르지 않고 실패 메시지가 보인다.

- [ ] 정한 MVP 완료 조건을 달성하면 성공 결과를 표시하고 플레이를 멈춘다.
  - Live Server 확인: 완료 조건을 달성하면 성공 메시지가 보이고, 주문 처리와 시간 진행이 멈춘다.

## 6. 가게 확장

- [ ] 보유 금액이 확장 비용에 도달하면 가게 확장을 실행할 수 있게 한다.
  - Live Server 확인: 필요한 금액을 모은 뒤 확장 조작을 할 수 있다.

- [ ] 확장 시 비용을 차감하고 가게의 확장 상태를 화면에 반영한다.
  - Live Server 확인: 확장 후 보유 금액이 줄고, 가게 화면이 확장된 상태로 바뀐다.

## 7. 재시작과 최종 점검

- [ ] 성공 또는 실패 결과에서 게임을 처음 상태로 다시 시작할 수 있게 한다.
  - Live Server 확인: 재시작하면 시간, 금액, 주문, 가게 상태가 초기값으로 돌아간다.

- [ ] Live Server에서 시작부터 성공·실패·재시작까지 전체 흐름을 점검한다.
  - Live Server 확인: 콘솔 오류 없이 주문 제작, 판매, 확장, 성공 또는 실패, 재시작이 모두 동작한다.
